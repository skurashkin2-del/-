# To-Do List для iOS (по дням недели и датам)

Красивый нативный iOS планер задач, написанный на **SwiftUI** с поддержкой iOS 16+. Разработан специально для удобного планирования дел по дням недели и датам.

---

## 🌟 Основные возможности

- **Лента дней недели**: горизонтальный календарь на 7 дней (Пн – Вс) с быстрой навигацией (Предыдущая неделя / Следующая неделя / Кнопка «Сегодня»).
- **Индикаторы задач**: счетчик оставшихся задач и галочки выполненных дел прямо под каждым днем в календаре.
- **Выбор любой даты**: встроенный всплывающий календарь для быстрого перехода к любому месяцу и году.
- **Управление задачами**:
  - Название задачи и подробные заметки/описание.
  - Точное время выполнения.
  - Приоритеты дел: *Низкий*, *Обычный*, *Срочный* с цветными бейджами.
  - Удобный чекбокс с тактильным откликом (Haptic Feedback) и анимацией вычеркивания.
  - Фильтры: *Все*, *В процессе*, *Готово*.
  - Удаление свайпом (Swipe-to-delete) и редактирование по нажатию.
- **Прогресс дня**: кольцевой индикатор выполнения задач на текущий день.
- **Полная автономность**: надежное локальное сохранение данных (UserDefaults JSON), работает без интернета.
- **Дизайн Apple Human Interface**: поддержка светлой и темной темы (Dark Mode), нативные шрифты и анимации.

## 🚀 Как получить готовый `.ipa` файл (без Mac, бесплатно через GitHub)

Поскольку сборка Mach-O бинарников для iOS требует среды Apple Xcode, в проект уже добавлен настроенный **GitHub Actions Workflow** (`.github/workflows/build-ipa.yml`), который компилирует `.ipa` в облаке на серверах Apple Silicon macOS.

### Шаг 1: Загрузите этот проект в свой GitHub

1. Создайте новый репозиторий на [GitHub.com](https://github.com/new) (например, `ios-todo-app`, можно сделать приватным).
2. В терминале в папке с этим проектом выполните:
   ```bash
   git add .
   git commit -m "Initial commit: iOS To-Do app"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ios-todo-app.git
   git push -u origin main
   ```

### Шаг 2: Скачайте готовый `.ipa`

1. Перейдите во вкладку **Actions** в вашем GitHub репозитории.
2. Вы увидите запущенный workflow **Build iOS IPA** (сборка занимает около 2-3 минут).
3. По завершении сборки кликните на выполненный запуск и в блоке **Artifacts** скачайте архив `ToDoList-IPA.zip`.
4. Внутри архива будет готовый файл `ToDoList.ipa`.

## 📲 Как подписать `.ipa` сертификатом разработчика и установить на iPhone

У вас есть сертификат разработчика (файлы `.p12` и `.mobileprovision`) или аккаунт Apple Developer. Установить приложение можно любым из следующих способов:

### Способ 1: Прямо с iPhone (через ESign, Scarlet или GBox)
1. Отправьте файл `ToDoList.ipa` на iPhone (через Telegram/AirDrop/iCloud Drive).
2. Откройте ваш установщик (например, **ESign** или **Scarlet**).
3. Импортируйте ваш сертификат разработчика (`.p12` + пароль и `.mobileprovision`).
4. Импортируйте `ToDoList.ipa`, нажмите **Подписать** (Sign) и затем **Установить** (Install).

### Способ 2: С компьютера Windows/Mac (через Sideloadly)
1. Скачайте и запустите [Sideloadly](https://sideloadly.io/).
2. Подключите iPhone по проводу.
3. Перетащите файл `ToDoList.ipa` в окно Sideloadly.
4. Введите ваш Apple ID или укажите файл сертификата.
5. Нажмите **Start** — приложение подпишется и сразу установится на ваш iPhone.

### Способ 3: Через Mac и Xcode (если у вас есть Mac)
1. Откройте файл `ToDoList.xcodeproj` в Xcode.
2. В разделе **Signing & Capabilities** выберите вашу команду разработчика (Team).
3. Подключите iPhone и нажмите **Run** (Cmd + R) или выберите **Product -> Archive**.
